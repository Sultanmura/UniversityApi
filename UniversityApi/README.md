# University Course Management API

Веб-служба RESTful API для системы управления университетскими курсами, разработанная на платформе **ASP.NET Core Web API**. Проект построен с соблюдением разделения на слои, использованием паттерна Repository, DTO и централизованной обработки ошибок.

## 🛠 Технологический стек и архитектура
* **Платформа:** .NET 8.0 / 9.0 (ASP.NET Core)
* **Доступ к данным:** Entity Framework Core (ORM)
* **База данных:** MS SQL Server
* **Маппинг данных:** AutoMapper (Разделение Database Entity ↔ API Contract DTO)
* **Архитектурный шаблон:** Repository Pattern (Слой доступа к данным абстрагирован от контроллеров)
* **Документация и тестирование:** Swagger / OpenAPI

### Схема архитектуры приложения:
Client (Браузер / Postman) 
   ↓ HTTP-запрос (JSON)
Controller (Атрибутная маршрутизация, Валидация DTO)
   ↓ 
Repository Layer (Абстракция CRUD-операций через IRepository<T>)
   ↓
Entity Framework Core & DbContext (Fluent API конфигурация моделей)
   ↓
Database (MS SQL Server)

## 📋 Реализованные бизнес-правила
1. **Правило №1 & №2:** Нельзя записать несуществующего студента или записать на несуществующий курс (проверка по базе перед транзакцией).
2. **Правило №3:** Один студент не может быть дважды записан на один и тот же курс (реализовано через составной уникальный индекс на уровне СУБД).
3. **Правило №4:** Курс не может ссылаться на несуществующего преподавателя.
4. **Правило №5:** Безопасная обработка: при запросе несуществующих ID API возвращает стандартизированную ошибку с HTTP-кодом `404 Not Found`.

## 🚀 Основные эндпоинты (API Endpoints)

### Студенты (Students)
* `GET /api/Students` — Получить список всех студентов
* `GET /api/Students/{id}` — Получить студента по уникальному идентификатору (ID)
* `POST /api/Students` — Добавить нового студента (валидация обязательных полей и формата Email)
* `PUT /api/Students/{id}` — Обновить персональные данные студента
* `DELETE /api/Students/{id}` — Удалить запись студента из базы данных

### Записи на курсы (Enrollments)
* `POST /api/Enrollments` — Записать студента на определенный курс (содержит проверку бизнес-правил и возвращает статус `201 Created` или ошибки `400`/`409`)
* `GET /api/Enrollments` — Получить реестр всех текущих записей студентов на курсы

## 🛡 Единый формат ответа и обработка ошибок
Все ответы API оборачиваются в универсальную структуру `ReturnResult<T>`.

* **Пример успешного ответа (200 OK):**
```json
{
  "statusCode": 200,
  "isSuccess": true,
  "result": {
    "id": 1,
    "firstName": "Иван",
    "lastName": "Петров",
    "email": "ivan@university.edu"
  },
  "errorCode": null,
  "errorMessage": null,
  "traceId": "a1b2c3d4-..."
}
```

* **Пример централизованной ошибки сервера (500 Internal Error):**
Глобальный `ExceptionHandlingMiddleware` перехватывает любые непредвиденные системные исключения, маскирует StackTrace от клиента и возвращает безопасный предсказуемый JSON:
```json
{
  "statusCode": 500,
  "isSuccess": false,
  "result": null,
  "errorCode": "INTERNAL_SERVER_ERROR",
  "errorMessage": "An unexpected error occurred on the server.",
  "traceId": "0HMV..."
}
```
